This is a simple GitHub Pages academic website inspired by a clean academic profile layout.

## Files included

```text
index.html
assets/profile.jpg
files/
README.md
EDITING_GUIDE.md
```

## How to publish it on GitHub Pages

1. Create a GitHub repository named:

```text
YOUR-GITHUB-USERNAME.github.io
```

2. Upload these files to the repository:

```text
index.html
assets/profile.jpg
README.md
EDITING_GUIDE.md
```

3. In GitHub, open the repository and go to:

```text
Settings → Pages
```

4. Under **Build and deployment**, choose:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

5. Save.

Your website should appear at:

```text
https://YOUR-GITHUB-USERNAME.github.io
```

## How to edit the page

Open `index.html`.

Look for comments that say:

```text
EDIT HERE
```

Those are the safest places to change text, links, and personal information.

Your current photo is already included as:

```text
assets/profile.jpg
```

If you want to replace it, upload another image with the same name.
